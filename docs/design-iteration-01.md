# Hybrid Engineering Studio — Design and release notes

## Design direction

Lightened slate-blue surfaces, pale-green highlights, technical type labels and reusable case-study layouts for game and software programming positions.

## Implemented pages

Home, project index and six project pages: Fortune's Gate, Site Zero, Takstrid, Grim Farmlore, Tic Tac Toe and Ninja Frog Adventure Saga.

Original project images and captions are stored locally under `public/media/`. Play/download pages are linked for Fortune's Gate, Site Zero and Ninja Frog Adventure Saga.

## Publishing safeguards

- Include source repository links only after public-visibility verification.
- Exclude private employer/client work.
- Keep the entire site self-contained.
- Keep production `main` unchanged until explicit launch approval.
